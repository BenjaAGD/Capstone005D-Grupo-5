# Diagramas del sistema DIRECTA

Esta carpeta contiene los diagramas técnicos y funcionales del sistema DIRECTA. En conjunto, muestran cómo está organizado el sistema, dónde se ejecutan sus componentes, cómo se relacionan entre sí y cómo circula la información durante sus principales operaciones.

Los diagramas cubren distintas vistas del sistema:

- **Contexto, contenedores y componentes:** usuarios, aplicación móvil Flutter, backend desplegado en Render, Supabase y servicios externos de IA.
- **Despliegue:** infraestructura y ambientes asociados a la ejecución del sistema.
- **Flujo de datos:** información que entra, se procesa, se almacena y se entrega.
- **Modelo de datos:** entidades, relaciones y estructura física de la base de datos.
- **Secuencias e interacciones:** mensajes que intercambian la aplicación, el backend, la base de datos y los servicios externos durante una operación.
- **Estados:** cambios que atraviesan documentos, análisis, sesiones, informes, señales e indicadores.
- **Actividades, casos de uso y BPMN:** tareas y procesos funcionales que realizan las personas y el sistema.

Algunas láminas representan el MVP actual y otras describen una arquitectura o flujo de destino. Cada diagrama identifica su alcance para que una propuesta futura no se confunda con una función ya implementada. El proveedor de IA se representa como externo mientras la API definitiva esté pendiente de confirmación.

Esta colección documenta la arquitectura, los datos y el comportamiento de DIRECTA. Los diagramas sobre la metodología de trabajo del equipo se mantienen fuera de esta carpeta.
